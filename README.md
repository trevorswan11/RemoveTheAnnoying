# RemoveTheAnnoying
A very simple lethal company created to remove game mechanics that my friends and I don't like playing with.

The mod will prevent all spawning of Barbers and Maneaters, and prevents the Mineshaft Interior from generating. It also provides options to bring Artifice back to its v56 glory days, weather modification, and to fix a bug with the company cruiser. In addition to these adjustments, this mod also provides the following:
- Total scrap value UI overlay when scanning inside of the ship

This mod was created so that my friends and I would be able to have more fun in our day-to-day playing. None of the code in this mod was AI generated, though the mod's thumbnail was generated by an AI model in early 2025.
